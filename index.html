1. Demander l'accès sur Discord

Pour des raisons de sécurité, l'adresse du serveur n'est pas publique. Seuls ceux qui donnent leur pseudo peuvent rejoindre.

  1. Va sur le Discord Les Sayenkru, dans le salon #minecraft-server.
  2. Sur ordinateur : clique sur l'icône Fils en haut à droite, puis sur Créer.
    Sur téléphone : appuie sur Créer un fil.
  3. Donne un titre au fil (obligatoire) et laisse Fil privé coché.
  4. Écris : @Trunks ou @Chef suivi de ton pseudo Xbox / Minecraft.
    Sur téléphone, mentionne plutôt @Trunks : les mentions de rôle marchent mal. La mention doit s'afficher en couleur.
  5. Envoie (touche Entrée, ou la flèche en bas à droite sur téléphone).

Tu recevras l'adresse du serveur en privé. Port : 19132 · Nom : Les Sayenkru

Rejoindre le Discord

2. Se connecter sur PC, téléphone, Xbox…

  1. Lance Minecraft → Jouer → onglet Serveurs.
  2. Descends et choisis Ajouter un serveur.
  3. Nom : Les Sayenkru · Adresse : celle reçue sur Discord · Port : 19132.
  4. Enregistre, puis Jouer.

3. Se connecter sur Nintendo Switch

Il faut un compte Microsoft/Xbox connecté à Minecraft et un abonnement Nintendo Switch Online.

  1. Sur la Switch : Paramètres → Internet → sélectionne ta box → Modifier les paramètres.
  2. Paramétrage du DNS : Manuel.
    DNS primaire : 104.238.130.180
    DNS secondaire : 8.8.8.8
    Puis Sauvegarder.
  3. Lance Minecraft → Jouer → onglet Serveurs.
  4. Choisis un serveur dont la description indique « Join To Open Server List ». Regarde bien la description, pas le nom : ça change d'une connexion à l'autre. (Conseil : « Mineville Zeqa » fonctionne le mieux, même si la description n'apparaît pas toujours.)
  5. Appuie sur Jouer : l'écran de BedrockConnect s'ouvre.
  6. Choisis Connect to a Server, entre l'adresse reçue sur Discord, laisse le port 19132, puis Envoyer.

Règles du serveur

  • En rejoignant le serveur, tu t'engages à respecter les règles.
  • Pour les nouveaux, un hôtel t'attend dans le village : lit, fourneau et établi à ta disposition.
  • Respecte les chambres et ne prends aucun objet.
  • Tu peux construire un coffre dans ta chambre, le temps de te construire une base.
  • Le non-respect des consignes (message dans le mauvais salon, pas de mention, propos inappropriés ou insultants) peut entraîner des sanctions.
